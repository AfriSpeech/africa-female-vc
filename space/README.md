Static demo for [AfriSpeech/africa-female-vc](https://huggingface.co/AfriSpeech/africa-female-vc).
The page calls a Modal-hosted GPU API (`deploy/modal_app.py` in
[the GitHub repo](https://github.com/AfriSpeech/africa-female-vc)); the server
scales to zero, so the first request after an idle spell includes a cold start.
